# chapter_init_notes 模板

> **用途**：每个章节动笔前，对引用的每个素材「逐块通读」时记录的阅读笔记。
> **位置**：`<项目目录>/<第N章>/chapter_init_notes/ch<N>_<file_basename>.md`
> **价值**：用户（或审查者）可能随时抽查「这个数字来自哪个 chunk、哪一行」，
> 笔记是回答抽查的凭证，也是防止「只读标题就扩写」的约束。
>
> 本模板为通用结构，请按实际素材填写，不要照抄占位文字。

## 模板

```markdown
# ch<N> - <file_basename>.md 阅读笔记

## 素材元信息

- **绝对路径**：
- **大小**：<human_size>
- **总行数**：<total_lines>
- **总 chunks**：<N>
- **语言**：中文 / 英文
- **read at**：<YYYY-MM-DD HH:MM:SS>

---

## chunk 0 (lines 1-<X>)

### 关键数据点（数字 + 行号）

- 行 <L>：<数字 + 单位 + 出处>
- 行 <L>：<数字 + 单位 + 出处>

### 关键论点（≤3 句）

1. <论点 1>
2. <论点 2>
3. <论点 3>

### 关键 URL（带标题）

- <URL 1> → <标题 1>
- <URL 2> → <标题 2>

### 与本章节的关联

<一段话说明这个素材对本章哪些小节有用>

---

## chunk 1 (lines <X>-<Y>)

（同上格式）

---

## 读后摘要

### 本素材 5 个最关键的事实

1. <事实 1>
2. <事实 2>
3. <事实 3>
4. <事实 4>
5. <事实 5>

### 与其他素材的关联 / 差异

- vs <素材 1>：...
- vs <素材 2>：...

### 不确定 / 矛盾之处

- <不确定性 1>
```

## 抽查回答格式示例

**被问**：ch3 用了某素材 chunk 2 的哪一个事实？

```
事实：<具体数值 / 结论>
来源：<素材名> 的 chunk <N>（约全文 <X>% 处）
原文摘录：「...关键原文...」
写入章节：第 <N> 章 § <小节> <标题>
```

## SOP 验证检查表

- [ ] 列出本章全部素材路径
- [ ] 为每个素材建 `chapter_init_notes/ch<N>_<basename>.md`
- [ ] 对每个素材逐 chunk 通读并写笔记（数据 / 论点 / URL / 关联）
- [ ] 全部 chunk 读完后跑 `reader.py verify`，5 字段全过
- [ ] 写读后摘要（5 个关键事实 + 关联 + 不确定性）
- [ ] 抽查回答模板就绪
